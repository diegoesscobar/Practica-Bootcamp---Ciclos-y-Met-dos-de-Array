# 🚀 Práctica Bootcamp - JavaScript (Devlights)

Este repositorio contiene ejercicios prácticos desarrollados durante el **Bootcamp 5.0 de Devlights**, enfocados en afianzar fundamentos de JavaScript, estructuras de control y manipulación de arreglos.

---

## 📚 Temas Practicados

- 🔁 **Ciclos e Iteraciones:** `for`, `while`, `do-while`
- 🔀 **Estructuras de Control:** `if`, `else if`, `else`, `switch`
- 🛠️ **Métodos Avanzados de Array:** `map`, `filter`, `find`, `reduce`, `some`, `every`
